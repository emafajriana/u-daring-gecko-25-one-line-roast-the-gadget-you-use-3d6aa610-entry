## The roast

> My smartwatch scores my sleep out of 100 every night, then buzzes me awake at dawn to report I got a 41 and must try harder at being unconscious.

## How it runs

`main.py` (Python 3, standard library only) writes the line to
`entry.txt` inside the output directory — `$MAKEFUN_OUTPUT_DIR` when set,
otherwise `/output` — then reads the file back and checks it against the
competition gate: UTF-8 text of 1–200 characters, not only whitespace.

```sh
python3 main.py
```
